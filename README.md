# 🏊 Aplikasi Booking Wisata Walini

Sistem informasi berbasis web untuk pemesanan tiket wisata Walini, Rancabali. Memudahkan pelanggan booking online, upload bukti bayar, dan mendapatkan E-Tiket digital.

## ✨ Fitur Utama

### 👤 Customer
- Registrasi & Login
- Cari & Pilih Destinasi
- Booking Tiket Online
- Upload Bukti Pembayaran
- Download E-Tiket (PNG)
- Lihat Fasilitas Destinasi

### 💼 Kasir
- Cek Pembayaran Masuk
- Konfirmasi/Tolak Booking
- Validasi Tiket di Lokasi

### 🔧 Admin
- Kelola Data Destinasi
- Monitoring Semua Booking
- Laporan Transaksi

## 🛠️ Teknologi
- **Backend:** PHP 8.2 (Native), PDO MySQL
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap Icons
- **Database:** MySQL / MariaDB
- **Server:** Apache (XAMPP)
- **Tools:** VS Code, Git, GitHub
